# CursoDeEmpresas
Base de datos para la cracion de cursos para un catalogo de empresas. Los usuarios que tengan el rol de Empresa podran subir sus cursos, examenes y certificaciones y pueden contar con metodos de pago. Mientras que los roles de user pueden contar con la opcion de visualizar las empresas y cursos, elegir a cuales anotarse y podes ver  su contenido
